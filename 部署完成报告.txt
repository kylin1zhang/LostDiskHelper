   ⚠️ 需要网络连接才能使用 AI 功能

                    ❓ 常见问题解答
═══════════════════════════════════════════════════════════

Q1: 为什么 exe 文件这么大？
A:  因为内置了完整的 Node.js 运行时（约 50MB）
    这样才能在没有 Node.js 的电脑上运行

Q2: 为什么 dist 文件夹不打包进 exe？
A:  - 保持 exe 文件大小合理
    - 方便更新网页资源
    - 提高资源加载性能

Q3: Windows Defender 提示病毒怎么办？
A:  这是误报，因为是新生成的 exe 文件
    点击"详细信息" → "仍要运行"即可

Q4: 可以在没有网络的环境使用吗？
A:  应用本身可以离线运行
    但使用 Gemini AI 功能需要网络连接

Q5: 支持其他操作系统吗？
A:  当前版本仅支持 Windows
    如需 Linux/Mac 版本，需要重新打包

Q6: 如何更新应用？
A:  重新运行 npm run package
    然后替换U盘中的文件即可
